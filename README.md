# PTT Stock Forum Web Scraping Project

## 專案簡介

本專案旨在透過 Python 實現網頁爬蟲，抓取 PTT Stock 版的文章標題，並進行資料分析與視覺化。通過這個專案，您將學習如何進行基礎的網頁爬蟲，如何處理並分析資料，並用圖表來呈現分析結果。

## 學習目的

在這個專案中，您將學習到以下技能：

1. **網頁爬蟲技術：**  
   使用 Python 的 `requests` 和 `BeautifulSoup` 套件來發送 HTTP 請求並解析 HTML 頁面，提取所需的資料（如文章標題）。

2. **分頁爬取：**  
   理解如何處理多頁數據，使用分頁來持續抓取資料，並設置爬取頁數限制。

3. **資料分析與視覺化：**  
   利用 `pandas` 進行資料處理，並使用 `matplotlib` 進行數據視覺化。這裡通過對文章標題長度的分佈進行統計分析，幫助您理解如何處理和分析文本資料。

4. **了解網站結構：**  
   解析網站的 HTML 結構，學會如何定位和抓取指定的資料。這是任何網站爬蟲專案的核心技能。

## 使用工具

本專案使用以下 Python 工具與套件：

- **`requests`**：用來發送 HTTP 請求，與網站進行互動並獲取頁面內容。
- **`BeautifulSoup`**：解析 HTML 內容，並提取所需的資訊，如文章標題。
- **`pandas`**：處理結構化資料，特別是對爬取的資料進行清理和轉換。
- **`matplotlib`**：用於數據視覺化，這裡用來繪製文章標題長度的分佈圖。
- **`threading`**（可選）：為了提高爬取效率，這個專案示範了如何使用多線程同時處理多頁面。
